# Code of Conduct

We want this project to be a welcoming place for students and developers of every background.

**Expected:** be kind, assume good intent, give specific and constructive feedback, and respect people's time.

**Not acceptable:** harassment, insults, discriminatory language, personal attacks, publishing other people's private information, or sustained disruption of discussions.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, open a private security advisory on the repository or contact a maintainer listed in the repository profile.

This policy is adapted from the Contributor Covenant, version 2.1.
